##  Executive Summary
This repository contains the code, data integration workflows, validation reports, and primary documentation for **Week 02** of the **Heavy Machinery Supplier Inventory & Warehouse Analytics** project (CadetX Virtual Work Experience). 

The primary focus of Week 02 was **Data Cleaning, Integration, and Validation**. The team successfully standardized relational data across 12 source ERP tables, addressed duplicate invoice records and stock ledger discrepancies, built a unified working dataset, and finalized key technical metadata.
